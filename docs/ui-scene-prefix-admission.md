# Admission and ownership

IEEE binary32/binary64, round-to-nearest, masked exceptions, gradual underflow, contraction/reassociation/fast-math disabled. Numeric expressions are bounded to1024 input bytes and32 recursive primary levels. Alias inputs/keys/values are bounded1024bytes, expanded output4096bytes,256 string constants and32 placeholder depth. These are explicit adapter limits, not recovered native allocation limits. `%`/`^`, outer localization, general malformed-input exception text and allocation failure are unsupported. Other native arithmetic consumers are not inferred from the dedicated condition contract.

Ordinary evaluator constants/results must be finite. The control consumer alone admits observed quietNaN/Inf/large conversion cases and outputs a bool; NaNpayload/FPflags/signalingNaNs/other CPU branches are not promised. Readinteger requires finite truncated signed32-representable input before conversion. Named boolean accepts only finite constants whose lround result is0or1, equivalent to exact half-boundary decisions; literal spelling/case is strict.

ItemInput follows the previously proved builder domain: parent sizes0..1e6; direction/mode0..3; finite relative/absolute values bounded+/-1e6; finite nonnegative view/context/desktop scales bounded1e6; every shifted integer conversion representable. All properties are caller-supplied sourceint32 fields; resulting item admission for a subsequent full Flex call is that solver's separate contract. No XML-1→auto-2 normalization is performed. Header defaults are conveniences/specified source-reader or selected base-store values, not full native widget factories.

Geometry prefixes require positive parent dimensions1..1e6 when a parent is present, intrinsic dimensions0..1e6, initial mode0..3, finite positive derived sizes and checked signed32 conversions. Prior bounds are bounded+/-1e6. No-parent ignores unused parent dimensions and preserves caller numericPW/PH. Generic parents do not consume Smart previous records. Numeric/string registries are caller-owned and must remain valid through calls; borrowed attribute/style views require their owners to outlive use. Feature state is explicit and immutable while queried.

Context+278 validation and childcheckBounds are independent; original raw-double predicates execute in the oracle. Only diagnostic stream setup/teardown is modeled, with no numeric comparison modeled. A bounds rejection returns a tagged result before integer conversion. Mutated numeric context can remain partially updated if later input throws; no rollback is guaranteed. The source prefix stops before THIS_W/H updates and later paint/lifetime work. Resource resolution and class-specific initial state are inputs rather than guesses.

Spec/item composition covers numerical source-supported member operations. It does not establish the actual factory registration timing, Flex listener setup, weak references, visibility/move/resize callbacks, external child entry, multi-observer event order, queues or widget lifetime. Those are required before a full scene-parity claim. Zero parent/spec division, background-image service, standalone startup geometry and complete cold construction remain separate domains.
