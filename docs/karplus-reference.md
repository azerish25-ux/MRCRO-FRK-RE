# KarplusStr reference core

The native core now contains the source-derived type3 KarplusStr model in core/include/mfrk/karplus.hpp and core/src/karplus.cpp. It produces 32 frames at 96 kHz and preserves the original integer exciter/string processing, control mapping, interpolation, clearing sequence, gain scaling and shared LCG updates. Numerical method bodies were moved out of the frozen candidate header into the production implementation; mathematical tables and state remain private with test-only friend access.

Construction explicitly admits a zero preconstructor arena. The original inline constructor writes 173 of 288 bytes; its unwritten bytes are not inferred factory defaults. Tables, the owner-shared random state and caller-owned 8192-short Memory must outlive each persistent, noncopyable model. Memory contents are supplied independently and construction does not clear them. Source address fields are inert oracle identity labels; the implementation never dereferences them. The actual buffer is the fixed Memory borrowed at construction. bind saves metadata and initialize commits it while clearing only the source-defined parameter fields.

The raw model reset and phase setter are original no-ops. Whole-slot reset additionally clears the slot resource in the native owner and remains a separate integration operation. Original owner traces show six voices, two sides and persistent per-side model banks: changing models preserves the same slot resource and inactive model histories. Harmo must use that external slot storage when the full owner is connected; its existing isolated owned-delay profile is not treated as the complete owner.

The phase position converts zero-extended uint32 to float, while remaining excitation uses signed modular subtraction. The shared scalar sine helper covers all finite float arguments under the identified UCRT FMA profile. The source exp2f helper uses its separately identified noncontracted double operations on finite exponents [-64,64]. Normal pitch rendering has no former finite-sine magnitude ceiling. Nonfinite intermediate math, alternate floating environments and errno/fenv side effects remain outside this return-bit reference. Counter tests inject boundary positions after 80 original warm blocks; they do not claim to reproduce continuous 12-hour histories.

Unchanged original fixtures check 8440 blocks / 270080 samples, all 552 generated coefficients, both sides and four constructor profiles; 854 lifecycle commands including 404 rendered blocks; 720 counter-boundary blocks / 23040 samples; and 6139 original import returns. Comparisons include complete recorded state, both rings, seed, excitation and raw/decoded/scaled output. All match locally. Seven Release checks verify rejection and rollback; 2048 ordinary/large-counter render blocks allocate nothing. The adapted repository reader also rejected all 33 retained malformed transport/schema variants. Fixture hashes and exact source entries are in core/tests/karplus_provenance.json.

All 57 host Release CTests pass. The GitHub Actions workflow builds both Android ABIs and runs all six Karplus checks on its x86_64 emulator; exact target results will be recorded after that revision finishes. This component does not establish a complete voice graph, effects/modulation/preset parity or a sounding standalone Android app. The current comparison APK remains test-only.
