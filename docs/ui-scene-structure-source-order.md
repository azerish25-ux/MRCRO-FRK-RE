# Source and operation order

Wrapper SHA256: `354c26c58e4c8c671b50f88d070452b47c9cd6b6505b1ea18391724929b3d19e`, source image base `180000000`.

The original whole-document constructor/move/parser route is `6f6a90 → 722ab0`. Mode 0 clears the current document links, skips a UTF-8 BOM and source whitespace, requires `<` between top-level records, and dispatches `72a340`. Mode 1 is a different path and is not exposed here.

`72a340` drops declarations, processing instructions, comments and doctypes in mode 0; retains CDATA type 3; and dispatches element parsing to `72e930`. That function reads the source name table, ordered attributes via `72f050`, and content via `72f5d0`. Attribute single/double-quote decoders are `72f9f0`/`72fc50`, text decoder `730350`, numeric byte emitter `730000`. All source character tables are recorded by address and exact bytes in `provenance/native-xml-character-tables-v1.json` and copied unchanged to `ui_scene_xml_tables.inc`.

Content skips pure source whitespace before markup, retains leading/trailing whitespace when a non-whitespace data segment exists, and sets the element value from the first data segment whose current native value starts with NUL. Closing names are consumed without comparing against the opening name. Unknown entities remain literal. The decimal entity loop uses the same source digit table as the hexadecimal loop; replacing it with a host decimal parser is observably wrong.

Style owner `9abd40` reads and resolves the first title, splits the first colon without trimming, and requires an already registered base. It clones the base through `1313139a0`; the allocation helper `1313138a0` initializes each cloned element value empty. Derived attributes are processed in source order: remove the FIRST same-name inherited attribute, detach the input attribute and prepend it. This reverses their final order while leaving other inherited duplicate entries intact. Derived children append recursive clones; equal names/titles do not replace inherited children. The FIRST `title` attribute is then removed. The derived input's attributes are consumed; children stay in the input. A plain style registers its original element instead of cloning it, which is represented here only as an owning immutable data snapshot.

The preserved portable bodies are the private Parser class, parser entry, style clone, remove-first and style definition. Namespace/includes/public DTO declarations and admission wrappers are packaging changes. `body-preservation.json` compares the complete portable bodies to frozen private reference snapshots; it is not a claim that C++ text is original source. Original-instruction oracle scripts, wrapper identity, decoded native ASTs and complete native style outputs provide the numerical-free behavioral evidence.

Continuation evidence is retained outside this packet: native `b5dcb0` collects `<with>` fields `src`, `src2`, ... with exactly one matching string/double/color field, before `b5e8c0` installs any collected bindings. Numeric collection has 76 original cases, including the stock matrix min/max and NaN path. Actual UI resource include tags are `xmlfile`, `predef-xml-file` and `template-xml-file`; plain `include` references found first belonged to MIDI loaders. Correct source owners `9ade70`, `9ab650`, `9aa550`, `9acdd0`, `9ad0e0`, `9ad240` are indexed for the next stage. Their full caller grammar/provider/version/error behavior is not approximated by this packet.
