# Native slot pitch preparation

The native core now preserves the numeric pitch-preparation path from source2cdad0 and PitchComputer323700. Its nine raw packed records use the recovered fixed metadata for both oscillator sides, including the piecewise mapping, ordered cached products and ten quantizer tables. The instruction-proven sum is (PC64+PC60)+(PC68+PC30), followed by the optional quantized term, clamp0..127 and separate frequency calculation. Flattening that sum changes the source result.

Input is the upstream field ABI: nine uint16 words, nine literal dirty bytes, base-note field and dirty/force byte. These are not inferred UI coarse/fine controls or a MIDI note setter. Both first prototype ranges are120/-60; correct frontend ranges depend on their upstream compilation. The caller must dispatch pitch whenever Result.recomputed is true, even if the frequency value stays equal, and still prepare the model each block. Nonfinite base-note rejection preserves state and Result.

The fixed-base2 UCRT powf slice follows the identified FMA branch, source double ln2/bin reduction, explicit FMA polynomial/table scaling and negative floor exponent adjustment. Source exp2f is not interchangeable: a verified counterexample differs by one float bit. All64 coefficients independently match a250-digit mathematical generation. The admitted exponent range is the actual clamped slot range[-5.75,floatbits409aaaab]; no host powf fallback or general special-value/errno/fenv profile is claimed.

The unchanged original1160-case sequential fixture executes the complete original slot preparation on one constructor-only owner slot, without restoring between records. It compares all112 recorded state bytes and the separately observed native cached-Hz write flag. The production test additionally compares returned note/Hz to original fields58/5c for every held and recomputed case. Swapping only those returned fields leaves state and dirty checks passing but causes2320 result failures, which the extended test catches.

The source powf fixture covers137161 original returns and separate Hz products, including actual owner producer inputs. Root freshly replayed every case against the actual SHA-pinned System UCRT with zero differences. All72 host Release CTests pass, seven moved method bodies match exactly,22 malformed fixtures reject, and independent strict actual-repository review finds no required fixes. Fixture/source identities, metadata and semantic controls are in core/tests/slot_pitch_provenance.json. Linux/Android results will be recorded for the exact published revision.

This is numeric slot preparation. The source upstream glide/base-note writer, parameter-word compiler, model forwarding/selection/dispatch, voice routing and standalone audio/UI/MIDI remain required. The current comparison app remains test-only.
