# Full finite source-profile scalar sine

The shared helper in core/src/ucrt_sinf.hpp reproduces the identified Windows UCRT scalar sinf FMA branch for finite IEEE binary32 inputs under round-to-nearest-even. This extends the previously tested ordinary range; its polynomial and ordinary reduction are unchanged.

The additional reducer follows source RVAs0xac490..0xac5e4 in SHA256 dedb7611e1abc1ff3852dcac3d4c93a048d729e25b061973b9969f22698f14ca. Three64-bit table words multiply the exact double significand using portable32-bit limb products. Carries, quadrant selection, one's complement (without adding one), normalization, exact double pi/2 multiplication and final sign handling follow the original instruction order. Explicit double FMAs remain required; implicit FP contraction and fast-math remain disabled.

Finite float exponents24..127 access only source2/pi bytes119..154. All36 bytes independently match a450-digit Machin-pi construction. The whole160-byte table differs at unreachable byte0; no general double-input reducer claim is made. An exhaustive integer-only sweep of872,415,232 positive large-float representations found no zero leading fraction, keeping normalization and shift operations defined. Both signs share that reduction. This sweep is a safety property, not an original audio comparison.

The unchanged original11951-case full-range compact fixture has SHA256 5f1147acc31965e8e37f10df189fcb8ada35f089a289aa2f1e97fd48544d80c3. Tests require signed zero, branch boundaries and maximum finite magnitudes to be admitted, while infinities and NaNs are excluded.
