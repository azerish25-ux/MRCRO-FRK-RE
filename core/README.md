# Portable instrument core

The core contains reconstructed oscillator, control, filter, resampling and main
ADSR components. Exact scopes and original-reference checks are recorded below.
It is not a complete instrument engine or an Android app.

`normalized_pitch_frequency` follows the original x64 helper at `0x18032e950`
in processor SHA-256
`bd036dfa6a0afcfef733c29c73b1b3df969f2c86ca860b0fa535d4492fa8fb74`.
Inputs must be finite. The function preserves internal pitch quantization and
the installed normalization constant. Do not assume a host sample-rate contract
from the name or replace the lookup with a continuous exponential.

The two 256-entry lookup tables come from Emilie Gillet's MIT-licensed
[stmlib units.cc](https://github.com/pichenettes/stmlib/blob/e3bd7c9cc00e4364166f9905c0509b6ffd0535ec/dsp/units.cc).
The original notice is retained in `src/pitch_tables.hpp`. A complete comparison
of their float32 bytes against the installed tables returned identical hashes:

| Table | SHA-256 of 256 float32 entries |
| --- | --- |
| High | `0dfd8bc6ea9e667907a4ef4d300369e6ea55bfb047130926627cbf03c1dcb54e` |
| Low | `ce9d87899dbdc1e5b59a1cd3b26107334c55d50aef782242944eb83d7c401cc6` |

The 661 test vectors were generated by bounded Unicorn x86-64 emulation of the
original instructions and original tables, independently of this C++ function.
They cover MIDI notes, fractional table boundaries and clamped out-of-range
inputs. They are finite-input samples, not an exhaustive proof for all floats.

GitHub Actions builds native checks, cross-compiles Android arm64-v8a/x86_64,
and runs the x86_64 checks inside an Android emulator. A passing math helper
does not prove full instrument, audio, UI, latency or real-device equivalence.

## Raw VAnalog component

`VirtualAnalog` follows the recovered Init/Render routines at `0x18032fe50` and
`0x18032fef0` in the same processor. It preserves oscillator state and gain
interpolation across calls. Construction allocates its implementation once;
rendering does not allocate or perform I/O. Output lengths must be 1..32 frames;
16 and 32-frame paths are currently tested.

[Verified run 41789935056](https://github.com/azerish25-ux/MRCRO-FRK-RE/actions/runs/41789935056)
reported 1,920 original-instruction VAnalog output samples with zero bit
mismatches on Android x86_64, alongside all 661 pitch cases. The 18 scenarios
include consecutive parameter changes and checks that rendering does not write
beyond a requested 16-frame output range. Both Android arm64 and x86_64 builds
passed; arm64 execution remains unverified.

MIT Plaits/stmlib oscillator primitives are pinned in `third_party/manifest.json`.
Two installed-engine rounding differences are explicitly preserved: variable-saw
output scaling and the multiplication order of the variable-shape wrap correction.
The manifest records original and modified file hashes; original notices remain.

This tests selected raw-engine parameter sequences, not every input or a complete
patch. Complete initialization, upstream control scheduling, note/voice behavior,
filters, effects and host-rate conversion still require reconstruction. Wrapper assembly shows a
16-frame engine call followed by a 2x interpolator producing 32 output frames.

## Interpolation and wrapper operations

`LinearUpsampler2x` follows routine `0x1802c9e60` and retains the previous sample
across blocks. Its input/output buffers must not overlap. Initial history is
caller-supplied. [Run 41792381316](https://github.com/azerish25-ux/MRCRO-FRK-RE/actions/runs/41792381316)
passed 1,920 direct and 1,280 composed VAnalog-chain output comparisons on the
GitHub-hosted Android x86_64 emulator.

`update_virtual_analog_controls` follows `0x1802c5570`: exact control-word scale
bits `0x37800200`, dirty flags, trigger consumption and latch transitions. It
preserves words, dirty bytes and note where the original leaves them unchanged.
This is a caller-owned representation of selected fields, not the native ABI layout.

`VirtualAnalogOscillator` composes the 16-frame raw engine, 2x interpolation and
caller-supplied level, following `0x1802c5380`/`0x1802c54b0`. It advances the engine
even during muted blocks. No factory output level is inferred from this API.

[Run 41794257456](https://github.com/azerish25-ux/MRCRO-FRK-RE/actions/runs/41794257456)
passed all earlier checks plus 64 original control-state updates and 1,280 original
output-wrapper samples with zero mismatches. Both Android ABIs built; execution
was on Android API 35 x86_64. GUI/MIDI scheduling, complete initialization,
voice/filter/effect routing, presets and the Android UI remain unverified.

## Basic Waves tables and raw engine

`BasicWaveTables` constructs 34 immutable mathematical tables and preserves the
original 128 bank selections. It uses ascending double-precision harmonic sums,
original coefficients and asymmetric +0.5/truncation. It ships no copied table
snapshots. Original live table bytes, original initializer emulation and independent
formulas agreed for all 17,408 unique signed-short values before implementation.

[Run 41800863961](https://github.com/azerish25-ux/MRCRO-FRK-RE/actions/runs/41800863961)
verified generated Android table bytes against all 128 independent SHA-256 bank
references. Construction is startup work, not an audio callback operation.

`BasicWaves` follows original pitch/table selection, phase seeding, reset, control
prepare and raw rendering. It preserves uint32 phase wrap, signed-short delta and
coefficient wrap, int64 pair accumulation and float conversion order. Its private
SRL/LPF state uses stored constructor coefficients rather than recomputing defaults.
Settled checks remain exact, including LPF float stagnation behavior.

[Run 41805177708](https://github.com/azerish25-ux/MRCRO-FRK-RE/actions/runs/41805177708)
passed 1,280 original-instruction output samples with zero bit mismatches on Android
API35 x86_64, including pitch changes, phase wrap, dirty preservation, initialized
controls, word overflow and negative frequency. All earlier checks and Android
arm64/x86_64 builds passed. arm64 execution and full voice/patch/application parity
remain unverified. Method ordering and initialization in tests are explicit fixture
conditions, not a claim about the complete original host scheduler.

## Raw model37 filter

`Vcf37` reconstructs normalized controls, double smoothing, nonlinear LP/BP/HP,
reset, explicitly seeded noise and DC blocking in 32-frame blocks. Construction
allocates once outside the audio callback. First/force/dirty flags belong to the
caller; reset preserves the PRNG seed. Use positive sample rates and finite
normalized controls in 0..1.

[Run 41813188815](https://github.com/azerish25-ux/MRCRO-FRK-RE/actions/runs/41813188815)
passed 7,680 original-instruction samples and 162 control blocks on Android API35
x86_64, plus all previous checks. Both arm64-v8a and x86_64 built; arm64 execution
remains unverified. Tests include high-resonance reset and five PRNG seeds with
noise toggling. Separate first-only/force-only sequences are not directly covered.
Independent review checked all 120 constants, both tables and the recovered core.

This excludes model49, dual selection, oversampling and complete voice placement.
See [routing evidence](../docs/filter-envelope-routing.md) for the recovered
envelope and voice boundaries. A full Android instrument and APK remain pending.

## Raw model49 filter

`Vcf49` adds the actual audio-rate second-input modulation path, four original
calibration curves, model49 capacitor compensation and variable block lengths.
It shares the verified nonlinear/reset/noise/DC stage with `Vcf37`. Cutoff and
resonance come directly from the current normalized records, including when
dirty flags are clear. Mode/noise latch only under their dirty flags or force;
first alone does not latch them. Unused fixed49 scalar/double caches are omitted.

[Run 41815081333](https://github.com/azerish25-ux/MRCRO-FRK-RE/actions/runs/41815081333)
passed 8,775 original model49 outputs and 135 block-end PRNG states on Android
API35 x86_64, with unchanged model37 and all earlier checks. Fixtures span
96/192/384kHz, 16..256 frames, dirty-clear/dirty/first/force writes, reset, output
modes and noise changes. arm64-v8a compiled; arm64 runtime is still unverified.

The binary fixture has an explicit little-endian versioned layout. Its generator
is `tools/generate_vcf49_vectors.py`; SHA256 is
`21cb834fa24197a9925c10d5ba225a06fece0a23e514fc7f298f9fe7877b6f6a`.
This node expects the actual internal sample rate and equally sized finite-input
spans. It does not supply the original oversampling, asynchronous resource/fade
wrapper, dual selection or full voice scheduler. Those remain required.

## Original filter resampling and settled model49 chain

`IirResampler` preserves all four original factors (2/4/6/8), exact coefficient
bits, eight-section float recurrence, insertion/gains, phase0 decimation and
separate persistent up/down state. Its reported descriptor latency is4 frames
at2x and5 at4/6/8x; graph latency alignment is still separate work.

`OversampledVcf49` upsamples both audio and modulation, renders raw49 at the
factor-scaled internal rate, then downsamples through the original IIR. Buffers
allocate during construction, with checked maximum capacity. Process does not
allocate. Reset clears resampler/filter state while retaining the noise seed.
This class is the fixed-resource, settled-gain1 inner chain, not the asynchronous
resource manager, factor transition fade or dual selector.

## Main fixed-point ADSR

`Adsr` preserves the recovered Q31 accumulator/Q15 output, mathematical curve
construction, nine ushort controls and dirty ordering, gate/legato/hold/reset,
five-tick retrigger and phase-specific coefficient updates. It uses explicit
two's-complement wrap, saturation and adjacent-field interpolation boundaries.
The decay target wraps to signed32 before its int64 product. Reset retains the
public output until the next step.

Construct outside the audio callback to prewarm both immutable curve tables.
Prepare all nine controls once before gate/step; their Boolean return means
portable API admission. Unwritten native ancillary cells are not claimed as
known constructor defaults. The raw hold setter does not invent external
pending-release dispatch. Test-only fixture loading is absent from the public API.

[Run41817910133](https://github.com/azerish25-ux/MRCRO-FRK-RE/actions/runs/41817910133)
passed all8,032 commands,7,032 asserted state records and3,600 original curve
bytes on Android API35 x86_64, plus earlier checks. Both ABIs built; arm64 was not
executed. Independent review covered original provenance, all five source maps,
arithmetic/state behavior, startup safety and the lossless fixture codec.

FX02 test data preserves every command, mask, argument and33-cell state array
from canonical original traces. The242,791-byte fixture decodes byte-identically
to the2,283,246-byte canonical data; provenance/hashes are in
`core/tests/adsr_fixture_manifest.json`. Generators are `generate_adsr_vectors.py`
and `compact_adsr_vectors.py` under tools. Full caller/clock/gate wiring and the
cyclic envelope still need integration and instrument-wide validation.

## FIR resources, adaptive selection and fades

`FilterResource` owns independent audio/modulation resamplers and startup-sized
buffers; it processes an externally owned raw49 filter. `OversampledVcf49` now
uses that resource for either original IIR or FIR profiles. `FirResampler`
preserves source taps, phase packing, four-lane float accumulation/reduction,
gain, histories and reset. No processing method allocates.

All selector outputs are represented: factor1 copies directly; factor3 IIR uses
the original missing-key zero-gain one-section fallback; factor3 FIR uses the
original single tap and gain3. Other profiles preserve their original coefficients.
`select_filter_factor` implements the original threshold/shift rules.
`FilterFade` preserves the32-sample vector grouping/clamping, including61-block
0→1/1→0 transitions at96kHz with0.02-second configured time.

## Deferred fixed49 controller and parameter caches

`DeferredVcf49` implements public initialization, prepare/render/end, deferred
request/worker/completion, fade ordering, latency publication and latest normalized
pending updates. Reset uses old controls before replay; PRNG and latched controls
survive replacement. Suspended render leaves output untouched and does not advance
DSP. This is a fixed49 child; the hardware37 child and Dual selector remain separate.

Private worker generations preserve the same logical state. Old allocations
retire on the worker; release/acquire publication protects handover. Control calls
are one actor; physical raw configuration requires an idle worker. Normal callback
paths allocate nothing. Initialization and the explicit direct-build context may
allocate. The host owns worker execution/joining. Native OS timing, ownership ABI
and arbitrary captured-state-command replay are not claimed.

Seven native records preserve incoming normalized bits, lazy cache origin, strict
noise thresholds, discrete endpoint quantization and normalized dirty comparison.
Snapshots include the raw-init aggregate mark published with a new generation.
